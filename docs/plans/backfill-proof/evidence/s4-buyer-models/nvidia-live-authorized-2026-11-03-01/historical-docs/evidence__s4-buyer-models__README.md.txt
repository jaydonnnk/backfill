## What changed

`/buyer` authenticates an existing buyer agent using its own bearer credential,
kept in page memory. It saves a private request and reference clock, requests
local Glimmer parsing, lets the buyer correct/review constraints, requests a
Spark Open decision using public offer fields, then requires separate exact
approval and submission. Parsing and review never authorize a commitment.

The private session binds party, run, request revision, rule, version,
occurrence, covers, per-cover price and total. Text or constraint edits clear
older decisions and approvals. Model attempts are reserved before dispatch;
duplicate requests cannot spend twice. In-flight results cannot restore edited
or discarded state. Each session has a 20-minute lifetime, six model attempts
and an authenticated party may create at most ten sessions per rolling day.
The separate proposed paid run is capped at five durable attempt slots.

Actual MCP tools perform public-term lookup, commitment submission and existing
settlement. The database transaction is shared through the Executor interface,
so concurrent approvals cannot exhaust the pool with nested connections. The
new local migration is `0016_proof_s4_buyer_sessions`. No persistent schema was
changed. Production still also needs the separately unapproved S3 migration.

A narrow S4 recording stores actual bounded model inputs/outputs and provenance.
Replay requires identical party, request, reference clock, reviewed constraints
and public offer/occurrence. It is labeled recorded replay and carries no old
approval or commitment. Legacy twenty-party recordings remain unchanged.

The local adapter refuses non-loopback addresses, credentials, unexpected URL
paths and redirects. The Gateway adapter uses installed `ai` 7.0.162,
`meta/muse-spark-open`, low reasoning, 512 output tokens, 45 seconds and
`maxRetries: 0`. It requests JSON text and revalidates it; native structured
output is not assumed. Gateway limits routing to the documented Baseten
upstream. Actual upstream identity is retained only when supplied. This is not
a direct Baseten integration or bonus eligibility proof.

Both product model dependencies default disabled. Their approval flags are
only for a separately approved local runner, which must also install the durable
Gateway guard. Do not enable an unguarded paid UI session. Unknown invoiced cost
stays null. Returned usage survives invalid final output; no hidden reasoning,
credentials, floor or owner voice record enters buyer/public payloads.

## Reproduce the local proof

Use installed Node 24 dependencies, Chromium and PostgreSQL 18.6. No dependency
install, real env file or provider key is needed.

```sh
npm run typecheck
npm run lint
env -u DATABASE_URL -u META_API_KEY -u AI_GATEWAY_API_KEY \
  TEST_DATABASE_URL=postgres://postgres@127.0.0.1:5432/postgres \
  S4_EVIDENCE_DIR=docs/plans/backfill-proof/evidence/s4-buyer-models npm test
```
